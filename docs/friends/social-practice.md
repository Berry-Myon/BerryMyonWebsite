## 红色故事与家风文化

第一篇新闻稿的主题是“红色”与“传承”。实践采用线上线下结合的形式，先后参观革命旧址、烈士陵园、民族博物馆和家风纪念馆。

路线如下：

| 地点类型 | 记录内容 |
| --- | --- |
| 革命旧址 | 参观军事指挥室、参谋室、故居、伙房和陈列房，了解相关会议和战略部署。 |
| 烈士陵园 | 瞻仰纪念碑，学习地方人民在革命事业中的牺牲与贡献。 |
| 民族博物馆 | 通过革命史展陈了解地方英雄事迹。 |
| 家风纪念馆 | 了解家学传承和爱国家风。 |

新闻稿最后把主题落在红色文化和家风传承上：家庭是人的第一所学校，良好家风能把精神力量带入学习与工作。

## 六盘山红军长征纪念馆

第二篇新闻稿记录的是六盘山红军长征纪念馆。展厅分为四个部分：

| 展厅 | 内容 |
| --- | --- |
| 红军不怕远征难 | 长征历史与革命文物。 |
| 红旗漫卷西风 | 红军经过六盘山区的斗争历史。 |
| 三军过后尽开颜 | 军民一心与建设家园。 |
| 不到长城非好汉 | 六盘山精神与长征精神。 |

原稿中写到，纪念馆展示了红军长征中的遗物、文物和图片资料，也复原了相关历史场景。纪念碑、纪念广场壁墙、纪念亭和吟诗台共同构成这次实践的线下路线。

新闻稿中的判断：即使身处相对和平安逸的环境，也要学习不怕吃苦、肯于钻研的精神，并从小事做起培养服务意识。

## 淮海战役纪念之旅

第三篇新闻稿记录的是淮海战役烈士纪念塔与纪念馆。路线包括纪念塔、烈士名录、浮雕壁画、纪念馆展陈和双拥展览馆。

原稿中对纪念塔的记录是：塔身正面镶嵌题字，下方碑文概括战役经过与胜利意义，塔上刻有烈士名录，并嵌有反映淮海战役的大型壁画。

纪念馆部分记录了淮海战役的进程：切断铁路、合围、支前、物资运输和战役胜利。新闻稿把重点放在人民力量上，写到江淮之间无数小推车运来粮食、炮弹和医疗物品，为战役胜利贡献力量。

## 三条主线

1. 革命旧址与家风文化。
2. 长征精神。
3. 淮海战役与人民支前。
