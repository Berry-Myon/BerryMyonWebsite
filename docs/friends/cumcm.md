# 大学生数学建模竞赛

<div class="course-layout" markdown="1">
<article class="course-main course-article" markdown="1">

## 基本记录

| 项目 | 记录 |
| --- | --- |
| 竞赛 | 大学生数学建模竞赛 |
| 结果 | 省级一等奖 |
| 顺位 | 1/3 |
| 题目 | 古代玻璃制品的成分分析与鉴别 |

这次比赛处理古代玻璃样品的成分分析、风化判断、类型分类和未知样本鉴别。关键词为：成分分析、数据挖掘、非参数检验、决策树、K 均值聚类、XGBoost。

## 风化特征分析

先对表单 1 做预处理，补全空缺颜色，再用 XGBoost 判断表面风化与玻璃类型、纹饰、颜色之间的关系。模型输入为颜色、类型、纹饰，输出为风化与否。训练验证比例为 0.7，调参后 F1 均值为 0.875。

| 特征 | 重要性 |
| --- | ---: |
| 类型 | 43.40% |
| 纹饰 | 36.20% |
| 颜色 | 20.40% |

之后用 Pearson 卡方检验继续看每个类别与风化之间的关系。检验结果为：铅钡类玻璃、B 纹饰玻璃样品更容易风化。

## 风化前成分预测

对风化样品，按“风化前后均值差”做修正。若风化样本某元素含量为 \(x_i\)，风化样本均值为 \(\mu_{w,i}\)，未风化样本均值为 \(\mu_{u,i}\)，则预测值写作：

\[
\hat{x}_i=x_i-(\mu_{w,i}-\mu_{u,i})
\]

预测结果用切比雪夫不等式检查。若某元素服从均值为 \(\mu_i\)、标准差为 \(\sigma_i\) 的分布，则有：

\[
P(|X-\mu_i|<3\sigma_i)\ge 1-\frac{1}{9}=0.8889
\]

报告中的统计结果如下：

| 类别 | 预测元素总数 | 位于 \(\mu\pm3\sigma\) 内 | 比例 |
| --- | ---: | ---: | ---: |
| 高钾类 | 84 | 84 | 1.000 |
| 铅钡类 | 378 | 358 | 0.947 |

最后采用这一步预测，把风化样品转成风化前成分，再进入后续分类。

## 高钾与铅钡分类

使用决策树对高钾玻璃和铅钡玻璃做二分类。分类规则很直接：氧化铅 \(\mathrm{PbO}\) 可以一步判别玻璃类型。模型评价指标如下：

| 数据 | 准确率 | 召回率 | 精确率 | F1 |
| --- | ---: | ---: | ---: | ---: |
| 训练集 | 1 | 1 | 1 | 1 |
| 测试集 | 1 | 1 | 1 | 1 |

## 亚类划分

亚类划分先用肘部法则与轮廓系数确定聚类数。最后采用高钾样本二分类、铅钡样本三分类。

高钾样本选取二氧化硅、氧化钾、氧化钙三种化学成分。稳定决策树得到二氧化硅单步划分阈值 \(73.736\%\)。

| 指标 | 亚类 1 \((n=15)\) | 亚类 2 \((n=3)\) |
| --- | ---: | ---: |
| 二氧化硅 \(\mathrm{SiO_2}\) | \(65.368\pm3.633\) | \(81.063\pm5.368\) |
| 氧化钾 \(\mathrm{K_2O}\) | \(10.223\pm1.962\) | \(4.870\pm4.718\) |
| 氧化钙 \(\mathrm{CaO}\) | \(5.951\pm2.084\) | \(2.240\pm2.363\) |

铅钡样本选取二氧化硅、氧化钙、氧化铜、氧化铅、氧化钡、二氧化硫六种成分做聚类。随后反复生成决策树，以 F1 大于 0.85 作为有效模型。总计运行 478 次后，得到 200 次有效决策树，取结点阈值均值作为最终分类阈值。

| 阈值 | 数值 |
| --- | ---: |
| 二氧化硅 \(\mathrm{SiO_2}\) | 52.042 |
| 氧化钡 \(\mathrm{BaO}\) | 17.812 |
| 氧化铅 \(\mathrm{PbO}\) | 25.325 |

铅钡亚类模型的测试集准确率为 0.929，召回率为 0.929，精确率为 0.946，F1 为 0.932。

## 未知样本鉴别与敏感性

未知样本先按二分类模型判断为高钾或铅钡。风化样本先转成风化前预测值，再按亚类模型分类。

| 样本 | 亚类 |
| --- | --- |
| A1 | 高钾 1 |
| A6、A7 | 高钾 2 |
| A3、A4 | 铅钡 1 |
| A2、A5、A8 | 铅钡 2 |

敏感性分析对核心化学元素加入 \(-5\%\) 到 \(+5\%\) 的扰动。铅钡亚分类、未知样本亚分类在扰动前后保持一致。结果记为：模型可以接受 \(\pm5\%\) 的测量误差。
