## 信息撰写

我在和睦街道综合事务岗进行了两个月实习，主要负责信息撰写，帮助办公室完成稿件整理。

刚开始做材料时，困难集中在三处：材料很难完全贴合要求或论点，时效性不好保证，有些稿件还有来源限制。经过多次沟通，也看了几篇范例文章后，我逐渐掌握了写作节奏。

实习期间，我完成了七篇信息撰写：

| 类型 | 数量 |
| --- | ---: |
| 问题建议 | 3 篇 |
| 政策约稿 | 3 篇 |
| 热点问题 | 1 篇 |

## 会议旁听

办公室工作之外，我旁听了多次会议。街道工作有大量细小事务，信息传递、沟通协调、文字表达都很重要。

基层工作给我的直接感受是：如果没有融入具体环境，很多事情看起来只是“琐事”；真正参与进去后，才能看到每一项事务背后的沟通链条和责任边界。
