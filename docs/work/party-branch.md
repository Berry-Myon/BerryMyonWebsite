## 党课一：科技自立自强

| 项目 | 记录 |
| --- | --- |
| 题目 | 科技自立自强 |
| 时间 | 2024-07-27 |

党课从科技发展方针的历史讲起：

| 时间 | 内容 |
| --- | --- |
| 1975 | 提出“独立自主，自力更生，艰苦奋斗，勤俭建国”。 |
| 2006 | 《国家中长期科学和技术发展规划纲要（2006—2020年）》确立“自主创新，重点跨越，支撑发展，引领未来”。 |
| 2016 | 《国家创新驱动发展战略纲要》提出“坚持走中国特色自主创新道路”。 |
| 2020 | 十九届五中全会把科技自立自强作为国家发展的战略支撑。 |
| 2021 | “高水平科技自立自强”进入相关讲话与法律修订。 |

理论内涵分为“自立”和“自强”：

| 概念 | 记录 |
| --- | --- |
| 自立 | 主要依靠自身力量掌握经济社会发展需要的技术和知识产权，主动作为，积极进取。 |
| 自强 | 将关键核心技术所有权、企业股权和知识产权掌握在自己手中，产业链和供应链的安全稳定不受外部干预影响，或外部影响处在可控范围内。 |

党课中还整理了科技发展经验：

- 坚持党的全面领导。
- 坚持走中国特色自主创新道路。
- 坚持创新引领发展。
- 坚持“四个面向”的战略导向。
- 坚持以深化改革激发创新活力。
- 坚持推动教育科技人才良性循环。
- 坚持培育创新文化。
- 坚持科技开放合作造福人类。

## 党课二：新时代党的建设和自我革命

| 项目 | 记录 |
| --- | --- |
| 题目 | 习近平总书记关于新时代新征程推进党的建设和自我革命的新部署新要求 |
| 时间 | 2025-01-23 |

党课记录了新时代党的建设的六个方面：

| 方面 | 要点 |
| --- | --- |
| 党的组织建设 | 坚持正确用人导向，促进能者上、庸者下、劣者汰。 |
| 党的作风建设 | 作风关系党群干群关系、人心向背。 |
| 党的纪律建设 | 纪律建设是全面从严治党的治本之策。 |
| 党的制度建设 | 以党章为根本遵循，健全党内规则体系。 |
| 党的政治建设 | 把准政治方向，提高政治能力。 |
| 党的思想建设 | 以理想信念保持团结统一。 |

全面从严治党体系按五个方向展开：

| 体系 | 记录 |
| --- | --- |
| 组织体系 | 上下贯通、执行有力。 |
| 教育体系 | 固本培元、凝心铸魂。 |
| 监管体系 | 精准发力、标本兼治。 |
| 制度体系 | 科学完备、有效管用。 |
| 责任体系 | 主体明确、要求清晰。 |

自我革命部分从历史、理论和现实三个角度展开。我在最后的启示中写下三点：批评与自我批评、理论学习、人民立场与社会实践。

## 师生交流会

| 项目 | 记录 |
| --- | --- |
| 活动 | “在鲜红的党旗下”师生交流会 |
| 时间 | 2024-12-26 |
| 形式 | 退休党支部与本科生第三党支部联合举办，本科生第一、第二党支部协办 |

交流会围绕学科奋进、专业发展和青年责任展开。退休教师分享了老一辈教育工作者的教育经历与治学精神，也谈到自动化专业在流程工业控制、无人机控制等方向的发展。

同学提问集中在控制学科的挑战与机遇、人工智能与自动化结合、青年学生如何参与国家和社会重大项目等问题。交流会最后落在“薪火相传，助力成长”上：学生党员要把专业学习、学术研究、实践工作和社会责任连起来。

## 年度总结

这一年里，我的支部工作主要围绕“规范发展、理论学习、活动组织、支部协同”展开。党员发展和转正工作要求流程严谨；党课要求先把材料读透，再把主题讲清楚；交流会需要协调多个支部和参与师生，让活动能顺利落地。
