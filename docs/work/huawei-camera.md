## 深度估计调研与选型

### 方法与测试场景

我调研并复现了以下方法：

| 方向 | 方法 |
| --- | --- |
| 双目深度估计 | RAFT-Stereo、Prompt-Stereo、Foundation-Stereo、Fast Foundation-Stereo |
| 单目深度估计 | Depth-Anything V2、Depth-Pro |

比较所用的输入包括标准数据集双目图像、重复纹理场景、含透明玻璃区域的双目图像、极线匹配较差的双目图像，以及仅有单目输入的图像。

### 典型问题与虚化效果

双目方法在天花板、人物条纹衬衫等重复纹理或大片同色区域出现了不合理的深度突变。这些区域的深度应平滑变化或近似一致。

单目方法有时把人物立牌当作真实人物，使同一平面上的内容被估计出前后深度关系。

原始 BokehMe 根据输入深度图计算虚化强度。当主体局部深度与对焦平面深度偏差较大时，主体也可能被错误虚化。

### 深度模块

我最终采用 Depth-Anything V2，默认使用 ViT-L。单目输入条件简单、运行较快，在实验样例中的深度估计效果较好。命令行支持切换模型类型。

## 自动化人像虚化框架

### BokehMe 渲染器

BokehMe 使用神经渲染器 NR 和经典渲染器 CR，通过误差图融合两者的输出：

| 渲染器 | 实验中关注的特点 | 融合方式 |
| --- | --- | --- |
| NR：神经渲染器 | 补充 CR 在边缘区域的不足，光斑生成效果不如 CR | 误差图数值较大的位置更偏向 NR 结果 |
| CR：经典渲染器 | 光斑生成效果较好，边缘区域容易出错 | 误差图数值较小的位置更偏向 CR 结果 |

### 处理流程

我串联了深度估计、主体分割、trimap 生成、精细抠图和虚化渲染五个环节：

```text
原始图像
├─ Depth-Anything V2 → 深度图 → 主体区域深度中位数 → 对焦平面
└─ BiRefNet → 腐蚀与膨胀 → trimap
                            └─ 原图 + trimap → MEMatte / 学生模型 → alpha 图

原图 + 深度图 + 对焦平面 + alpha 图
→ BokehMe（alpha 修正虚化强度，NR 与 CR 融合）
→ 最终虚化图像
```

BiRefNet 的分割结果用于生成 trimap，不额外进行 mask 阈值处理。腐蚀和膨胀采用方形核，核大小由输入超参数控制。trimap 中前景赋值为 1，背景为 0，未知区域为 0.5，随后结合原图输入 MEMatte，得到 alpha 图。

### 自动确定对焦平面

原流程需要手动传入对焦平面的深度值。我将其改为取主体区域深度的中位数：

\[
d_{\mathrm{focus}}
=\operatorname{median}\left\{D(p)\mid p\in\Omega_{\mathrm{subject}}\right\}.
\]

其中，\(D\) 为深度图，\(\Omega_{\mathrm{subject}}\) 为选取的主体区域。

### 输入与参数配置

框架通过 Python 在命令行调用，支持单张图像或整个文件夹输入。

| 类别 | 可配置内容 |
| --- | --- |
| 输入与深度模型 | 单图或文件夹输入，Depth-Anything 模型类型，默认 ViT-L |
| trimap 生成 | 腐蚀与膨胀强度 |
| 图像分块 | 分块大小、重叠区域大小 |
| 注意力计算 | 全局注意力能够关注的最大 token 数量 |
| 虚化控制 | 虚化强度控制超参数 |
| 运行环境 | GPU 配置 |
| 中间结果 | 深度图、mask、trimap、alpha 图 |

我通过中间结果检查深度、分割、抠图和渲染阶段的问题。

## 主体细节处理

### Matting 方法选择

我比较了 ViTMatte 和 MEMatte 对发丝、耳饰等细节的处理。在测试样例中，MEMatte 的显存占用明显低于 ViTMatte，细节效果略好。我采用 MEMatte，极细发丝仍会出现漏检。

### 初始方案：alpha 结果融合

最初，我将 MEMatte 放在虚化结果之后，用 alpha 图控制原图和虚化图的融合比例：

\[
I_{\mathrm{out}}=\alpha I+(1-\alpha)B.
\]

其中，\(I\) 为原图，\(B\) 为原始虚化图，\(\alpha\) 为 MEMatte 输出的 alpha 值。alpha 越大，最终结果保留的原图比例越高。

前景物体遮挡人物时，直接融合难以保留遮挡物边缘虚化形成的半透明过渡。

### 改进方案：alpha 虚化强度抑制

我提出将 alpha 信息接入 BokehMe，在计算出原始虚化强度 \(r\) 后进行修正：

\[
r'=r(1-\alpha)^M,\qquad M=4.
\]

\(r'\) 为修正后的虚化强度。取 \(M=4\)，是为了加强对可能属于主体的区域的保护。

| alpha 值 | 强度变化 |
| --- | --- |
| \(\alpha=0\) | 原始虚化强度保持不变 |
| \(\alpha=1\) | 虚化强度被抑制为 0 |
| \(0<\alpha<1\) | alpha 越大，抑制越强。\(M=4\) 比 \(M=1\) 进一步降低这些位置的虚化强度 |

### 实验观察

| 场景 | 原有问题 | 使用强度抑制后的观察 |
| --- | --- | --- |
| 主体局部深度与对焦平面深度差距较大 | BokehMe 将部分主体错误虚化 | 在所测样例中，相关主体部位不再被错误虚化 |
| 前景物体遮挡人物 | 直接融合难以保留遮挡物边缘虚化产生的半透明过渡 | 保留了这类遮挡过渡效果 |

## MEMatte 显存优化与模型蒸馏

### 全局注意力 token 上限

我调低了 MEMatte 全局注意力的最大 token 数量，以降低显存占用。初始值沿用模型默认设置，调整后原先因显存溢出（OOM）中断的推理能够运行。

### 分块处理与未知区域裁剪

我还尝试了两种缩小图像输入范围的方式：

| 方式 | 实现 | 实验观察 |
| --- | --- | --- |
| 分块处理 | 按配置的大小和重叠范围分块，处理后加权拼接 | 降低显存占用。分块过小时出现明显拼接痕迹 |
| 未知区域裁剪 | 根据 trimap 的 unknown 区域选取矩形，处理后将裁剪区域的输出还原至对应位置 | 降低显存占用。人物占图比例较大时，优化收益不明显 |

### 教师与学生模型

我采用 ViT-B 作为教师、ViT-S 作为学生，蒸馏对象为最终特征图。本次训练的结构配置如下：

| 配置项 | 教师模型 ViT-B | 学生模型 ViT-S |
| --- | ---: | ---: |
| embed_dim | 768 | 384 |
| depth | 12 | 12 |
| heads | 6 | 12 |

训练损失包括已知区域、未知区域及边缘区域的 L1 损失、Sobel 梯度一致性约束和 MSE。

### 蒸馏与微调配置

我在同一训练流程中完成蒸馏和微调，使用 P3M-10k 已划分的训练集和验证集。

| 项目 | 配置 |
| --- | --- |
| 数据集 | P3M-10k |
| 训练输入 | 随机裁剪为 512 × 512 |
| trimap 生成 | 使用 GenMask 在线生成 |
| 优化器 | AdamW |
| 学习率策略 | 分层学习率衰减 |
| 基础学习率 | \(2\times10^{-5}\) |
| 训练方式 | 单卡 |
| Batch size | 16 |
| Epochs | 30 |
| 训练耗时 | 约 3 小时 |

### 集成结果

我将训练后的学生模型接入完整虚化流程，并交付微调权重。在图像样例的视觉比较中，学生模型的最终虚化效果接近原模型，参数量有所降低。
